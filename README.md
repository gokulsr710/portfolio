# Portfolio — Electrical & Electronics Engineer

A single-file portfolio site with a circuit-board theme, a rolling photo strip, a link-tree style links page and a built-in editor.

## Use it

Open `index.html` in a browser, or host the folder on any static host (GitHub Pages works: Settings → Pages → deploy from the `main` branch).

- **Links page:** add `#links` to the site address.
- **Editor:** click the logo 5 times quickly and enter the password. Change the password in the editor's Settings tab.

## Publishing edits

Edits made in the editor are saved in that browser only. To show them to every visitor:

1. In the editor, open Settings and press **Export data.json**.
2. Put `data.json` next to `index.html` and upload it with the site.

The editor gate keeps casual visitors out; it is not real security, because the site has no server. Do not store secrets in it.
